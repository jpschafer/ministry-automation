# Sexton privacy policy

_Last updated: November 27, 2026_

Sexton is a private, self-hosted tool that runs our churches' live streams. It is
not a public service: nobody outside our ministry is meant to sign in to it, and it
has no website, accounts or sign-up.

## What Sexton accesses

When the person who manages our church's YouTube channel signs in, Sexton is
granted access through the YouTube API to manage **that channel's live
broadcasts**. It uses that access only to:

- create a live broadcast when a service starts streaming,
- connect the stream to it, check whether it is live, and
- end it when the service is over.

It does the same for our Facebook Pages and the Facebook profile it is set up for.

Sexton does not read, collect or store viewers' information, comments, messages,
subscribers, analytics, or any other personal data.

## What Sexton stores

Sexton keeps no database or files about anyone. The only things it holds are the
access credentials (tokens) for the accounts above. They are kept as private
settings on our own server, used only to make the calls listed here, and never
shared with or sold to anyone.

## Sharing

Sexton shares no data with third parties. It only talks to YouTube (Google) and
Facebook (Meta) on behalf of the accounts that authorized it.

## YouTube API Services

Sexton uses YouTube API Services. By authorizing it you also agree to the
[YouTube Terms of Service](https://www.youtube.com/t/terms), and Google's handling
of data is covered by the [Google Privacy Policy](https://policies.google.com/privacy).

Sexton's use of information received from Google APIs complies with the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Removing access

You can revoke Sexton's access at any time:

- Google/YouTube: [myaccount.google.com/permissions](https://myaccount.google.com/permissions)
- Facebook: Settings → Apps and Websites

Once access is revoked, Sexton can no longer do anything with that account, and it
has nothing else of yours to delete.
